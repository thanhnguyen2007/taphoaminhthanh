# Cửa Hàng Tiện Ích MiniShop - Hệ Thống Quản Lý Kho & Bán Hàng (Nhóm 5)

Dự án website quản lý kho hàng và đặt hàng trực tuyến, xây dựng bằng PHP & MySQL, hỗ trợ thanh toán COD và mã VietQR tự động.

## 📁 Thư mục mã nguồn
Toàn bộ mã nguồn của dự án nằm trong thư mục: [Nhom5/](Nhom5/)

## 🛠️ Công Nghệ Sử Dụng
- **Backend**: PHP (PDO MySQL)
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap 5.3
- **Database**: MySQL / MariaDB (XAMPP)

## 📋 Hướng Dẫn Cài Đặt & Chạy Demo
1. Mở XAMPP và Start **Apache** & **MySQL**.
2. Truy cập `http://localhost/phpmyadmin` và tạo database `inventory_shop`.
3. Import file `database.sql` (trong thư mục `Nhom5/database.sql`).
4. Đặt thư mục vào `c:/xampp/htdocs/Nhom5/` và truy cập trình duyệt: `http://localhost/Nhom5`
